# heartfix HF-01 — лендинг

Ремкомплект для разбитого сердца. Первый экран и глава 01 «Поломка».

## Как открыть

Шрифты подгружаются из Google Fonts, поэтому нужен интернет. 3D работает только через локальный сервер: если открыть `index.html` двойным кликом, браузер может не загрузить скрипты.

Самый простой способ запустить сервер:

```
cd heartfix-site
python3 -m http.server 8000
```

Потом открыть в браузере `http://localhost:8000`.

Можно и через расширение Live Server в VS Code.

## Что где лежит

```
heartfix-site/
├── index.html        разметка страницы
├── css/style.css     стили, анимации, кнопки
└── js/
    ├── three.min.js  библиотека 3D (three.js r149)
    ├── binder.js     привязка данных к разметке
    └── main.js       логика страницы
```

### Что делает main.js

- 3D-сердце в стиле скетча: чернильный контур, штриховка и «дрожание» линий
- лоток с 16 деталями и сборка по кнопке «Начать сборку» / «Разобрать обратно»
- режим «Заглянуть внутрь» с крупным планом
- окно детали с вращающейся 3D-моделью: открывается по клику на деталь
- пульт с процентами и статусом сборки
- колесо глав слева и глава 01 «Поломка»

### Привязка данных

Значения на странице берутся из функции `renderVals()` в `main.js`:

| Атрибут в разметке | Что делает |
| --- | --- |
| `data-text="name"` | текст элемента |
| `data-bt-style="[[name]]"` | атрибут style, так же работают `class`, `href` и `aria-*` |
| `data-bt-onclick="[[name]]"` | обработчик клика |
| `<template data-for="list" data-as="item">` | повторяет блок для каждого элемента списка |
| `<template data-if="flag">` | показывает блок, только если `flag` истинный |

Тексты деталей лежат в `main.js` в массиве `PARTS_INFO`. Тексты поломок лежат там же, в `OBJS`.
